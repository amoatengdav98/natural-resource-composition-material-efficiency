# Data dictionary

The cleaned master dataset contains one row per country/economy and year, with the following fields.

| Field | Description |
|---|---|
| `Country` | Country/economy label used in the material-flow source |
| `Country Code` | Harmonised country/economy code used for merging |
| `Year` | Calendar year |
| `DMC/GDP` | Domestic material consumption per unit of GDP |
| `GDP/MF` | GDP per unit of material footprint |
| `NRR` | Total natural-resource rents (% of GDP) |
| `Oil` | Oil rents (% of GDP) |
| `Gas` | Natural gas rents (% of GDP) |
| `Coal` | Coal rents (% of GDP) |
| `Mineral` | Mineral rents (% of GDP) |
| `Forest` | Forest rents (% of GDP) |
| `GDPpc` | GDP per capita, constant 2015 US dollars |
| `Industry` | Industry value added (% of GDP) |
| `Trade` | Trade (% of GDP) |
| `Urban` | Urban population (% of total population) |
| `Renewable` | Renewable energy consumption (% of total final energy consumption) |
| `FDI` | Foreign direct investment, net inflows (% of GDP) |

Variable names and units follow the merged research dataset. Source database definitions should be consulted for the exact statistical scope and revisions of each indicator.
